# sort_excel

受託確認票などのExcelデータを管理し、用途別に整形 / 並べ替え / 書式設定を行って出力するシステムです。
本リポジトリには、用途に応じて利用できる2つのエディションが含まれています。

* 社内LAN対応 Webサーバー版 (`sort_excel_server.exe`)
  * 社員全員がブラウザから同時に案件の閲覧 / 登録 / 編集を行えるスタンドアロン型Webサーバーです。
  * ブラウザ上での日付別スケジュール閲覧、選択式と自由入力を両立した入力フォーム、操作者記録と改ざん不可の監査ログ、IPアクセス制御、社員から管理者への不具合報告とGitHub Issues起票連携、ワンクリックでのデスクトップショートカット作成、全画面表示、自動Excel生成と多層バックアップを備えています。
  * 詳細な使い方や機能一覧は [README_SERVER.md](README_SERVER.md) を参照してください。
* デスクトップGUIアプリ版 (`sort_excel.exe` / `sort_excel.py`)
  * 手元のExcelファイルを読み込み、用途別に整形 / 並べ替え / 書式設定を行って出力する単体PC向けのデスクトップアプリケーションです。
  * 画面から担当順やソートキーを変更でき、設定を保存して繰り返し利用できます。

## デスクトップGUIアプリ版の主な機能

* デスクトップGUI画面
  * 高DPI対応により、Windowsの拡大倍率が設定されているディスプレイでも文字や枠線がにじまず鮮明に表示されます。
  * フラットでシンプルなカード型デザインを採用し、操作状態や進捗ログが直感的に把握できます。
  * ファイル選択ダイアログのほか、枠内クリックやドラッグ / ドロップによるファイル読み込みに対応しています。
  * 処理の進捗ログが画面上に表示され、完了後は保存先フォルダや出力ファイルをそのまま開くことができます。

* 不具合報告機能
  * 画面上部およびヘルプタブから、不具合報告ダイアログをいつでも呼び出せます。
  * OSやアプリバージョン、直近の処理ログなどの環境診断情報を自動収集し、GitHub Issuesの作成ページへ直接引き継ぐことができます。
  * GitHubアカウントがない場合でも、報告文をワンクリックでクリップボードにコピーしたりテキストファイルへ保存できます。
  * 並べ替え処理でエラーが発生した際も、ダイアログからワンクリックでエラー詳細を引き継いで報告フォームを開けます。

* ヘルプと権利表記
  * 専用の ヘルプ / 権利情報 タブおよびメニューバーを整備しています。
  * 基本操作、対応シートや列の仕様、トラブルシューティングの解説を画面上で確認できます。
  * 本アプリのMITライセンス情報に加え、利用している主要オープンソースライブラリの権利表記を確認できます。

* 担当順の調整と保存
  * 日付別シートのソートに使用する担当者の優先順位を並べ替えることができます。
  * 担当者の追加、削除、五十音順ソート、初期値へのリセットに対応しています。
  * 変更した設定はJSONファイルに保存され、次回起動時にも自動的に反映されます。

* ソート条件と出力シートのカスタマイズ
  * 日付別シート内の並べ替えキーを最大3つまで指定でき、昇順 / 降順を選択できます。
  * 融資実行日シート、金消日 / 面談日シート、統合データシート、日付別シートの出力有無を個別に切り替えられます。
  * 行の高さや自動更新確認の有無を画面から変更できます。

* 自動書式設定
  * 文字がセルからはみ出さないよう、縮小して全体を表示する設定を適用します。
  * すべてのセルの外枠と内枠に点線罫線を付与します。
  * 行の高さを統一し、上下左右中央揃えを適用します。
  * 列の種類に応じた見やすい幅を自動設定します。

## 画面構成と使い方

### GUIでの操作

実行ファイルである sort_excel.exe をダブルクリックするか、以下のコマンドを実行して起動します。

```bash
python sort_excel.py
```

* 並べ替え実行タブ
  * 入力ファイルを選択するか、ドロップ領域へExcelファイルをドラッグします。枠内をクリックしてファイル選択を開くこともできます。
  * 保存先ファイル名は自動で設定されますが、必要に応じて変更も可能です。
  * 並べ替えを実行する ボタンを押すと処理が開始されます。

* 担当順の設定タブ
  * 日付別シートで優先する担当者リストを編集します。
  * 上にある担当者ほど優先的に上に並びます。
  * 未登録の担当者は末尾に配置されます。

* ソート / 書式設定タブ
  * 日付別シート内の第1キーから第3キー（識別、担当、時間など）と昇順 / 降順を設定できます。
  * 出力するシートの種類や行の高さ、起動時の自動更新確認を設定できます。

* ヘルプ / 権利情報タブ
  * 使い方ガイド、トラブル対処法、著作権表記やMITライセンス、利用OSSライセンスを確認できます。
  * 不具合報告フォームの呼び出しやGitHub Issuesへのアクセスも行えます。

### コマンドラインやドラッグでの操作

引数としてExcelファイルのパスを渡すと、ファイルを読み込んだ状態でGUIが起動します。
また、exeファイルに対してExcelファイルを直接ドラッグ / ドロップして開くことも可能です。

```bash
python sort_excel.py <Excelファイルパス>
```

付属の sort_excel.bat にExcelファイルをドラッグ / ドロップして実行することもできます。

## 処理の流れ

```mermaid
flowchart TD
    A[Excelファイル入力] --> B[シート自動判定]
    B --> C[データ読み込みと日付変換]
    C --> D[融資実行日 / 金消日データの抽出]
    D --> E[統合データの生成]
    E --> F[日付別シートの生成と並べ替え]
    F --> G[openpyxlによる書式設定]
    G --> H[Excelファイル出力保存]
```

## コード解説とモジュール構成

プロジェクトは保守性と拡張性を考慮し、役割ごとにモジュールを分離しています。

* server/
  * Rust（Axum + SQLite + rust_xlsxwriter）で実装された社内LAN向けWebサーバー版（`sort_excel_server.exe`）のソースコード一式です。詳細は [README_SERVER.md](README_SERVER.md) を参照してください。

* sort_excel.py
  * デスクトップGUI版のエントリーポイントです。
  * コマンドライン引数を解析し、GUIの起動やファイル読み込みの橋渡しを行います。

* gui_app.py
  * 高DPI対応のTkinterデスクトップGUI画面の実装です。
  * 並べ替え実行、担当順設定、ソート / 書式設定、ヘルプ / 権利情報の各タブUIを提供します。
  * 不具合報告機能や環境診断情報の収集、エラー通知ダイアログとの連携を行います。
  * 画面の固まりを防ぐため、Excel処理はバックグラウンドスレッドで実行され、進捗メッセージをログ領域に逐次表示します。
  * windndライブラリが利用可能な場合は、ウィンドウへのドラッグ / ドロップによるファイル読み込みを有効化します。

* sort_core.py
  * Excelデータの読み込み、整形、並べ替え、書式適用を担当するコアエンジンです。
  * シート検出ロジックでは、受諾確認票、受託確認票、Sheet1、シート1の順に対象シートを探索し、見つからない場合は先頭シートを採用します。
  * Pandasを用いて融資実行日データと金消日面談日データを抽出し、標準化された列順序に揃えて統合します。
  * 日付ごとのシートでは、設定された優先キーに基づいて行を並べ替えます。
  * 書式設定処理ではopenpyxlを使用し、全セルへ点線罫線、上下左右中央揃え、縮小表示、列幅および行の高さを適用します。

* config_manager.py
  * 担当者リストやソート条件、書式設定などの永続化を担当します。
  * 通常のスクリプト実行時とexe実行時の両方で、適切なファイルパスを自動判定して sort_excel_config.json へ読み書きします。
  * 設定ファイルが存在しない場合や破損している場合は、安全に初期値へ戻します。

* sort_excel_config.json
  * ユーザーが保存した設定値を保持するJSONファイルです。
  * 担当者の並び順、ソートキー、シート出力オプション、書式設定値、更新確認の設定が保存されます。

* updater.py
  * GitHub Releases から最新版を確認し、exe のダウンロードと差し替えを行うモジュールです。
  * リポジトリやIssuesへのURL定義も保持しています。
  * 標準ライブラリのみで実装しているため、追加の依存はありません。

* version.py
  * アプリのバージョン番号を 1 か所で管理するファイルです。

* sort_excel.spec
  * PyInstaller用のビルド構成ファイルです。
  * 配布用exeのファイルサイズを軽量化するため、torchやscipy、matplotlibなどの不要な重いモジュールを除外設定しています。
  * icon.ico や LICENSE ファイルを同梱して単一の実行ファイルとして配布できるよう構成されています。

## データ仕様

### 対象シートと主要列

入力ファイルでは以下のいずれかのシート名が自動認識されます。

* 受諾確認票 / 受託確認票 / Sheet1 / シート1

想定している入力列は以下の通りです。

* 融資実行日、金消日・面談日
* 形態、お客様氏名、物件、依頼内容、担当、管轄
* 立会時間、立会場所、立会者、当日申請
* 金消時間、金消場所・面談場所、意思確認

### 出力されるシート

* sorted_by_融資実行日 : 融資実行日順に並べ替えたシート
* sorted_by_金消日・面談日 : 金消日・面談日順に並べ替えたシート
* 統合データ : 融資実行日と金消日の両データを日付昇順で統合したシート
* 各日付シート : 統合データを日ごとに分割し、指定された優先順位でソートしたシート

### 自動適用される書式

* セル配置 : 上下中央揃え / 左右中央揃え
* セル書式 : 縮小して全体を表示
* 罫線 : すべてのセル枠に点線罫線
* 行の高さ : 25（設定で変更可能）
* 既定列幅 : 
  * お客様氏名 : 約115px
  * 物件 : 約160px
  * 場所 : 約160px
  * その他の列 : 約80px

## 配布用 exe の作成方法

PyInstallerを利用して、Python未導入のPCでもそのまま起動できる単一のexeファイルを作成できます。

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --clean sort_excel.spec
```

ビルドが完了すると、dist/sort_excel.exe が生成されます。dist と build は Git の管理対象外で、配布は GitHub Releases のみで行います。

## 自動アップデート

exe を起動すると、裏で GitHub Releases の最新版を確認します。新しいバージョンがあれば変更内容を表示したダイアログが開き、次の操作から選べます。

* 今すぐ更新する : 新しい exe をダウンロードして SHA256 を照合し、差し替えてから再起動します
* 後で : 今回は更新せず、次回の起動時にもう一度通知します
* このバージョンをスキップ : そのバージョンについては以後通知しません

ヘルプのメニューにある更新を確認からも手動で確認できます。ネットワークに繋がらないときは何も表示せずにそのまま起動します。設定は exe とは別のファイルに保存されているため、更新しても引き継がれます。

起動時の確認を止めたい場合は、設定画面のチェックを外すか、sort_excel_config.json の update にある auto_check を false にしてください。

exe を書き込み権限のないフォルダに置いている場合は差し替えに失敗します。その場合はデスクトップやドキュメントなど、ユーザーが書き込めるフォルダに置いてください。

## リリース手順

GitHub Actions がタグの push を受けて、exe のビルドと Release の作成を自動で行います。

```mermaid
flowchart LR
    A[version.py を更新してコミット] --> B[タグを push]
    B --> C[GitHub Actions でビルド]
    C --> D[Release に exe と sha256 を添付]
    D --> E[各PCのアプリが起動時に検知]
```

```bash
# version.py の __version__ を 2.1.0 に更新してコミットしたあと
git tag v2.1.0
git push origin main v2.1.0
```

* タグは小文字の v を付けた v2.1.0 の形式にしてください。V2.0.0 以前のタグはそのまま残しています
* タグと version.py の番号が一致しない場合、ワークフローはエラーで止まります
* リリースノートは前回のリリースからの変更をもとに自動で作られます。必要に応じて Release のページから編集してください

## トラブルシューティング

* シートが見つからないエラーが出る場合
  * Excelファイル内に対象シートが含まれているか確認してください。
* 時間列の並び順が期待通りにならない場合
  * HH:MM や H:MM:SS 形式の文字列であれば自動で秒数換算して並べ替えます。判定できない特殊な形式の場合は末尾に配置されることがあります。
* 列幅がExcel上でわずかに異なって見える場合
  * Excel内部の文字幅単位への近似換算を行っているため、使用フォントや環境により多少の差異が発生する場合があります。
