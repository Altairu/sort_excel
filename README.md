# sort_excel

Excelファイルの受諾確認票シートを読み込み、用途別に整形 / 並べ替え / 書式設定を行って出力する軽量デスクトップアプリケーションです。
GUI画面から担当順やソートキーを柔軟に変更でき、その設定を保存して繰り返し利用できます。

## 主な機能

* 軽量 / 高速なGUIインターフェース
  * Python標準のGUIをベースに設計されており、瞬時に起動して軽快に動作します。
  * ファイル選択ダイアログのほか、ドラッグ / ドロップによるファイル読み込みに対応しています。
  * 処理の進捗ログが画面上に表示され、完了後は出力ファイルや保存先フォルダをワンクリックで開けます。

* 担当順のカスタマイズと保存
  * 日付別シートのソートに使用する担当者の優先順位を自由に並べ替えできます。
  * 担当者の追加、削除、五十音順ソート、初期値へのリセットが可能です。
  * 変更した設定はJSONファイルに保存され、次回起動時にも自動的に反映されます。

* ソートキー / 出力シートの設定
  * 日付別シート内の並べ替えキー（第1から第3キー、昇順 / 降順）を変更できます。
  * 融資実行日シート、金消日 / 面談日シート、統合データシート、日付別シートの出力有無を選択できます。
  * 行の高さや列幅などの表書式設定を調整できます。

* 自動書式設定
  * 縮小して全体を表示（Shrink-to-fit）
  * すべてのセルへの点線罫線（dotted）の適用
  * 行の高さや上下中央揃え、列幅の自動調整

## 使い方

### GUIで実行する場合

以下のコマンドを実行するか、実行ファイル（sort_excel.exe）をダブルクリックして起動します。

```bash
python sort_excel.py
```

* 画面上のドロップ領域にExcelファイルをドラッグ / ドロップします。
* 必要に応じて担当順の設定タブやソート設定タブで並び順を調整します。
* 並べ替えを実行するボタンをクリックします。

### コマンドラインまたはドラッグ実行

実行ファイルにExcelファイルを直接渡して実行することも可能です。

```bash
python sort_excel.py <Excelファイルパス>
```

## 配布用 exe の作成方法

PyInstallerを用いて単一のexeファイルを作成できます。

```bash
pyinstaller sort_excel.spec
```

作成された dist/sort_excel.exe を配布することで、Pythonがインストールされていない環境でも動作します。

## ファイル構成

* sort_excel.py : アプリケーションのエントリーポイント
* gui_app.py : 軽量デスクトップGUI画面
* sort_core.py : Excel読み込み、並べ替え、書式適用のコアロジック
* config_manager.py : 設定ファイルの読み込みと保存
* sort_excel_config.json : ユーザー設定保存ファイル
* sort_excel.spec : PyInstallerビルド設定ファイル
