    このシステムの基本的な仕組み

    受託した案件の新規登録や、融資実行日 / 金消日 / 担当者などの更新をブラウザから安全に行えるシステムです。
    複数の社員が同時に操作してもデータが壊れることがなく、画面で保存した瞬間に共有フォルダの 受託確認票.xlsx が最新の状態で自動生成されます。

    操作者（あなたの名前）の設定と切り替え

    • 初回アクセス時に表示されるポップアップで自分の名前をクリックすると、ブラウザに記憶されます。
    • 画面右上の 操作者 プルダウンからいつでも自分の名前を確認したり、別の担当者へ切り替えたりできます。
    • リストに自分の名前がない場合は、プルダウン一番下の + リストにない名前を追加... から新しい名前を登録できます。
    • 動作テストを行う際は、本番の担当者リストに影響しない テスト用（動作確認） を選んで操作してください。

    上部5つの画面タブの使い分け

    • 案件一覧（全件管理）: 登録されているすべての案件を検索や担当者・ステータス絞り込みで確認する基本画面です。
    • 日付別スケジュール（ソート済み）: 左側のカレンダー日付リストをクリックすると、その日の融資実行日と金消日 / 面談日の予定が、担当者の優先順位と時間順に整列して表示されます。今日 / 直近へ ボタンで当日の予定へすぐ移動できます。
    • 融資実行日順シート / 金消日・面談日順シート / 統合データシート: Excelの各シートと同じ並び順で一覧表示されます。上部検索枠でそのシート内の絞り込みも可能です。
    • どのタブを表示しているときでも、表の行をクリックすればそのまま右側に編集パネルが開いて内容を修正できます。

    新規登録と編集のポイント（自由入力対応）

    • 新規登録は右上の + 新規案件を登録 ボタンから、既存案件の修正は一覧の行をクリックして行います。
    • ステータス、担当、形態、依頼内容、当日申請は表記ゆれを防ぐため選択式になっていますが、選択肢の一番下にある その他（自由入力...） を選ぶとテキスト入力欄が開き、選択肢にない特殊な内容でも直接記入して保存できます。
    • 融資実行日や金消日がまだ確定していない場合は、ステータスを 日程未定 または リスケ にし、日付の横にあるメモ / 補足欄に予定時期（例: 来年3月予定）を記入してください。
    • 金消場所や先方書士、備考欄は改行して複数行で入力できます（売主側と買主側の情報を分けて書く場合などに便利です）。
    • もし同じ案件を別の人が先に更新していた場合は、上書きを防ぐための通知が表示されますので、一度画面を更新してから再度編集してください。

    便利な機能（全画面表示 / Excel出力 / 削除と復元）

    • 全画面表示: 右上の 全画面表示 ボタンを押すと画面いっぱいに表が広がり、たくさんの案件を一度に見渡せます（Escキーで元に戻ります）。
    • Excelを今すぐ出力: 保存時に自動でExcelも更新されますが、右上のボタンから手動で最新Excelを再出力することも可能です。
    • 案件の削除: 編集パネル左下の 削除 ボタンを押すと一覧から消えますが、データ自体は管理者のゴミ箱に保管されるため、誤って消してしまった場合でも管理者に連絡すればいつでも復元できます。

    共有フォルダの 受託確認票.xlsx を見るときの注意

    • 共有フォルダのExcelファイルは、いつでも開いて閲覧や印刷を行えます。
    • ただし、Excel上で直接セルを書き換えて保存しても、次に誰かがWeb画面から保存した際にWeb側のデータで上書きされます。データの修正は必ずこのWeb画面から行ってください。
    • また、Excelファイルを開いたままにしていると自動更新の妨げになるため、確認や印刷が終わったらExcelを閉じておくようご協力をお願いします。

    不具合を見つけたときや改善要望がある場合

    画面右上の 不具合 / 要望報告 ボタンから、気になった点やエラー内容を入力して送信してください。内容はいったんシステム管理者へ報告され、管理者が確認のうえ対応いたします。

    不具合 / 改善要望を管理者へ報告

    システムを使っていて気づいた不具合や、使いにくい点・改善してほしい要望があればご記入ください。送信された内容はまずシステム管理者へ届きます。
