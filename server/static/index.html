使い方ガイド / 操作マニュアル

1. 日常の使い方の流れ

受託した案件の登録や、日時の決まった案件の更新はすべてこの画面から行います。
画面で保存した内容は、社内共有フォルダの「受託確認票.xlsx」へ即座に自動反映されます。

2. 案件の更新手順（日時決定・担当変更）

  • 上部の検索窓にお客様氏名や物件名を入力して案件を探します。
  • 一覧の行をクリックすると、右側に編集パネルが開きます。
  • 融資実行日や金消日、担当者などを選択・入力し、「保存してExcel更新」を押します。

3. 入力時のルールとポイント

  • 日程の入力: 確定した日付はカレンダーから選んでください。まだ日程が決まっていない場合はステータスを「日程未定」または「リスケ」にし、日付メモ欄に予定時期を記入してください。
  • 複数日程や売主/買主の別: 金消場所や先方書士欄などは複数行（改行）で入力可能です。
  • 表記ゆれ防止: 形態や依頼内容、担当はドロップダウンから選択してください。

4. 共有Excel（受託確認票.xlsx）の閲覧について

共有フォルダにある「受託確認票.xlsx」は、誰でも直接開いて確認できます。
ただし、直接Excel上でセルを書き換えて保存することは避け、更新はこのWeb画面から行ってください。
