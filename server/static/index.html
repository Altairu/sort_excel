    日常の使い方の流れ

    受託した案件の登録や、日時の決まった案件の更新はすべてこの画面から行います。
    画面で保存した内容は、共有フォルダの 受託確認票.xlsx へ即座に自動反映されます。

    案件の更新手順

    • 上部の検索窓にお客様氏名や物件名を入力して案件を探します。
    • 一覧の行をクリックすると、右側に編集パネルが開きます。
    • 融資実行日や金消日、担当者などを選択および入力し、保存してExcel更新を押します。

    選択肢にない項目を入力したい場合

    • 担当、形態、依頼内容、当日申請、ステータスの各選択肢の一番下に その他（自由入力...） があります。
    • これを選ぶとすぐ下にテキスト入力欄が表示され、選択肢にない特殊な内容でも自由に記入して保存できます。

    共有Excelの閲覧について

    共有フォルダにある 受託確認票.xlsx は、誰でも直接開いて確認や印刷ができます。
    ただし、Excel上で直接セルを書き換えて保存すると自動出力で上書きされるため、データの更新はこのWeb画面から行ってください。
