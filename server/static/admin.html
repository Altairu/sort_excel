Excel出力時の日付別シートで並べる優先順位を設定します。既存のPython版ツールと同じく、最大3段階のソートキーと担当者の並び順を自由に変更できます。

    ※ 既定値は 第1キー: 識別(降順) / 第2キー: 担当(昇順) / 第3キー: 時間(昇順) です。

    選択肢マスター管理

    使用者画面のドロップダウンに表示される定型選択肢を編集します（1行につき1項目）。
    ここになくても、使用者は入力画面で その他（自由入力...） を選んで直接記入することも可能です。

    Excel出力先 / 自動化・バックアップ保持設定

    ソート済みExcelファイルの出力先フォルダやファイル名、データ更新時の自動出力のオン/オフを設定します。

    ※ 社内共有フォルダのパスを指定すると、そこへ直接最新のExcelを出力します。

    既存Excelファイルの一括データ取り込み

    既存の受託確認票Excelファイルから案件データを読み込みます。重複登録を防ぐため、追加モードか総入れ替えモードを選択できます。

    バックアップ一覧 / データ復元

    毎日深夜に自動作成される日次バックアップと、手動バックアップの一覧です。万が一の際は指定した日付の時点へデータを復元できます。

    保存先: ./backups/ フォルダ
    バックアップ日付 更新日時 Excelファイル データベースファイル 操作

    ゴミ箱（削除済み案件の復元 / 完全削除）

    使用者画面から削除された案件はここに保管されます。誤って削除した場合は元の状態に復元できます。
