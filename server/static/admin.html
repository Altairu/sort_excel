    セキュリティについての注意事項と本システムの対策内容

    お客様の大切な個人情報や案件データを安全に管理するため、本システムに組み込まれている防御機能と、運用上ご注意いただきたいポイントをまとめています。

    運用上のセキュリティ注意事項（管理者の方へ）

    • インターネット（社外）へのポート開放は行わないでください: 本システムは社内LAN（オフィス内のネットワーク）での利用を前提として設計されています。ルーターのポート転送機能などを使ってインターネットへ直接公開しないでください。社外から利用する必要がある場合は、必ず社内VPNなどを経由して接続してください。
    • 管理者権限のIP付与は必要最小限に限定してください: 管理者権限を付与されたIPアドレスのPCからは、全データの入れ替えや完全削除、他PCのアクセス遮断が行えます。管理者権限の付与は信頼できる管理担当者のPCのみに限定し、PCの入れ替えや配置変更があった際は速やかに解除してください。
    • 社内PCのIPアドレス変動（DHCP）にご注意ください: ルーターやWi-Fiの設定によっては、PCを再起動した際にIPアドレスが自動的に変わることがあります。特定IPへの管理者権限付与やアクセス遮断を行う場合は、対象PCのIPアドレスを固定するか、定期的にアクセス履歴タブで確認してください。
    • サーバーPC本体とデータファイルの物理的な管理: サーバーPC内の data.db および backups/ フォルダには全案件のデータが保存されています。サーバーPCのWindowsログインパスワードを必ず設定し、離席時は画面ロックを行うなど、第三者がファイルをUSBメモリ等で持ち出せないよう管理してください。
    • Excel出力先（共有フォルダ）のアクセス権限: 自動生成される 受託確認票.xlsx の保存先フォルダは、業務で閲覧が必要な社員のみがアクセスできる共有権限に設定しておくことを推奨します。

    このソフトウェアで実装しているセキュリティ対策とデータ保護機構

    対策項目 本システムでの実装内容と防御の仕組み
    完全ローカル / 社内LAN完結設計 外部のクラウドサービスや外部サーバーへ案件データを一切送信しません。データベース（SQLite）もWeb画面のプログラムもすべて sort_excel_server.exe 単一ファイル内に閉じ込められており、外部への情報漏洩経路を持たない設計です。
    管理者画面と管理APIの接続元制限 管理者コンソール（/admin）および管理用API（設定変更、Excel一括インポート、バックアップ復元、ゴミ箱の完全削除、IP制限操作など）は、サーバーPC自身（localhost）または管理者が許可したIPアドレスからのみ実行可能です。一般の社員PCからURLを直接入力してもサーバー側でブロック（403 Forbidden）されます。
    不正端末の即時IP遮断（出禁機能） すべての通信に対してミドルウェアで接続元IPアドレスを検査しています。アクセス遮断リストに登録されたIPアドレスからは、画面の表示もデータの取得 / 送信も即座に遮断されます（サーバーPC自身を誤って遮断しない安全機構付き）。
    外部サイトからの不正操作防止（CORS無効化） クロスオリジン通信（CORS）を無効化しているため、万が一社員がブラウザで悪意のある外部Webサイトを開いたとしても、その外部サイトから社内サーバーのデータを読み取ったり書き換えたりすることはできません。
    改ざん不可（追記専用）の監査ログ いつ / どのIPアドレスから / 誰が / どの案件のどの項目をどう変更したか（変更前後の差分）をすべて自動記録します。監査ログには削除機能や編集APIを一切設けておらず、管理者であっても過去の操作履歴を消去できない設計により高い透明性を確保しています。
    初回アクセスIPの操作者登録とガイド表示 初めてアクセスしたIPアドレスの端末には、操作者の選択画面と使い方ガイドを最初に自動で開き、誰がどの端末から利用を開始したかを記録します。
    SQLインジェクション / XSS対策 データベースへの読み書きはすべてパラメータバインド（プリペアドステートメント）で行い、画面表示時もHTMLエスケープ処理を徹底しているため、不正な記号やスクリプトが入力されてもシステムやデータが破壊されることはありません。
    不正ファイル書き出し防止と排他ロック Excel出力ファイル名にフォルダ移動文字（.. や / や \）が含まれる場合は保存を拒否し、指定フォルダ外への不正なファイル上書きを防止しています。また、複数人が同時に保存ボタンを押してもExcel生成処理が衝突しないよう排他制御（Mutexロック）を行っています。
    同時編集の上書き防止と多層バックアップ 同じ案件を複数人が同時に開いて編集した場合、バージョン番号の照合（楽観的ロック）により後から保存した側へ警告を表示し、意図しない上書き消去を防ぎます。また、削除操作はゴミ箱への移動（論理削除）とし、Excel上書き直前の退避ファイルと日次自動バックアップにより、誤操作時でも即座に復元できます。
    SHA256ハッシュ検証付き自動アップデート GitHub Releases から新バージョンの sort_excel_server.exe をダウンロードする際、同時に公開される .sha256 チェックサムと厳密にハッシュ照合を行い、破損や改ざんがないことを確認してから実行ファイルを差し替えて再起動します。

    自動アップデート / バージョン管理 (GitHub Releases 連携)

    GitHub Releases (Altairu/sort_excel) に公開されている最新リリースを確認し、ワンクリックで sort_excel_server.exe の自動ダウンロード、SHA256チェックサム照合、実行ファイルの差し替え、およびサーバーの自動再起動を行います。データベース（data.db）や設定はすべてそのまま引き継がれます。
